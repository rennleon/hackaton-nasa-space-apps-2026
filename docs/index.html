Trend Detective

Find, measure and test trends in NASA Earth science data. NASA Space Apps Challenge 2026: “Be an Earth System Trend Detective”.

AI disclosure. This video was scripted, recorded and captioned with Claude Code (an AI assistant by Anthropic), and the app’s code was written with AI assistance. The app itself uses no AI: every number comes from NASA data and our own statistics code. The same notice is burned into every frame of the video.

How it answers the challenge

  1. Identify variables worth investigating. Pick a plain question (heat, water, air); the tool lists the variables that can answer it, each with a plain definition, a reason to look, and a second instrument as a cross-check.
  2. Acquire data for a region. Ready-made regions (Cajamarca highlands in Peru, Wisconsin) work offline; any point or box on the map uses NASA POWER and NASA Giovanni.
  3. Time series and visualisation. 20+ years of monthly data with the seasonal cycle removed, one dot per year and the trend line.
  4. Rate of change and significance. Sen’s slope per 10 years with a 95% range; a trend counts only when the persistence-aware Mann–Kendall (Hamed–Rao) test and the OLS t-test with effective sample size agree at α = 0.05.

A Simple view a 9-year-old can read and a Scientific view with the full numbers; English and Spanish; a guided demo tour; a “You found a real change!” badge with a detective notebook and a shareable report.
