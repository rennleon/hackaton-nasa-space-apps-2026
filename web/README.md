# Earth System Trend Detective, web front end

Vite + React + TypeScript (strict). Charts: Plotly (`plotly.js-basic-dist-min`). Map: Leaflet + OpenStreetMap tiles.

## Run
```
npm install
npm run dev          # http://localhost:5173
npm run build | preview | test -- --run | lint | typecheck
npm run gen:types    # ../contract/*.schema.json -> src/types/contract.ts (generated, never hand-edit)
```

## Where the data comes from
`src/data/client.ts` defines the `DataClient` interface; components only use it (via `useData()`).
`src/data/index.ts` is the single place that picks the client:
- default: `StaticClient`, reads `public/data/...` (`catalog/*.json`, `results/<region>/scan_<theme>.json`, `<variable>.json`, `<variable>__<season>.json`).
- `VITE_API_URL=http://localhost:8000`: `FallbackClient(ApiClient, StaticClient)`. API first, static on failure. A custom period with no static twin returns the default result flagged `customPeriodUnavailable`, and the UI shows a notice.

API endpoints: `GET /regions /themes /variables /glossary`, `/regions/{r}/scan?theme=`, `/regions/{r}/variables/{v}?season=`, `/regions/{r}/variables/{v}/analyze?start=&end=&season=` (start/end as `YYYY-MM`).

## Mock data
`public/data` is MOCK, generated by `python3 scripts/make_mock_data.py` (needs PyYAML) from `../catalog/*.yaml`. Results carry `"_mock": true` and synthetic values. The backend precompute job overwrites these files with real output.

## Notes
The URL hash is the router (`#/shortlist?region=...&theme=...`). The Simple/Scientific choice is kept in localStorage. Catalog types (`src/types/catalog.ts`) are hand-written because they are not in the JSON Schemas.
